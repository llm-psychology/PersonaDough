# Location Manager 修復說明

## 問題描述

原本的 `backend.py` 中無法抓取到 `location_manager` 的 `location object`，導致位置管理功能無法正常運作。

## 問題原因

1. **缺少導入**: `backend.py` 沒有導入 `location_function_tools.py` 中的 `location_manager`
2. **API 端點不完整**: 位置相關的 API 端點沒有使用 `location_manager`，而是使用硬編碼的位置列表
3. **缺少位置**: 預設位置定義中缺少 `park_default` 位置

## 修復內容

### 1. 添加導入
```python
# 在 backend.py 中添加
from location_function_tools import location_manager
```

### 2. 更新位置 API 端點

#### 獲取所有位置
```python
@app.get("/api/location/all-locations")
async def get_all_locations_api():
    # 使用 location_manager 獲取所有位置
    locations = []
    for location in location_manager.locations.values():
        locations.append({
            "id": location.id,
            "name": location.name,
            "type": location.type,
            "position": location.position,
            "description": location.description
        })
```

#### 新增位置管理 API 端點
- `GET /api/location/{location_id}` - 根據ID獲取特定位置
- `GET /api/location/type/{location_type}` - 根據類型獲取位置
- `GET /api/location/character/{character_id}/preferred` - 獲取角色偏好位置
- `POST /api/location/character/{character_id}/preferred` - 設定角色偏好位置

### 3. 添加缺少的位置
```python
# 在 location_function_tools.py 中添加
"park_default": LocationInfo("park_default", "預設公園", "Park", {"x": 15.0, "y": 5.0}, "預設公園"),
```

## 修復結果

### 測試結果
- ✅ 成功獲取 14 個位置（原本 13 個，新增 1 個公園）
- ✅ 可以根據 ID 獲取特定位置
- ✅ 可以根據類型獲取位置（如 Home 類型有 5 個位置）
- ✅ 可以獲取角色的偏好位置
- ✅ 可以設定角色的偏好位置

### 可用的位置類型
- **Home**: 5 個位置（預設家、1號房子、2號房子、A棟公寓、B棟公寓）
- **School**: 2 個位置（預設學校、小學、中學）
- **Workplace**: 2 個位置（預設工作場所、A公司、B公司）
- **SoccerField**: 1 個位置（預設足球場）
- **Restaurant**: 1 個位置（預設餐廳）
- **Park**: 1 個位置（預設公園）

### 角色偏好位置系統
每個角色都有：
- **偏好位置**: 對每種類型位置的偏好設定
- **已知位置**: 角色認識的所有位置
- **家位置**: 角色的住所

## 使用方式

### 1. 獲取所有位置
```bash
GET /api/location/all-locations
```

### 2. 獲取特定位置
```bash
GET /api/location/{location_id}
```

### 3. 獲取類型位置
```bash
GET /api/location/type/{location_type}
```

### 4. 獲取角色偏好位置
```bash
GET /api/location/character/{character_id}/preferred
```

### 5. 設定角色偏好位置
```bash
POST /api/location/character/{character_id}/preferred
{
    "location_type": "Park",
    "location_id": "park_default"
}
```
