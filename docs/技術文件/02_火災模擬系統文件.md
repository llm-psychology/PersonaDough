## 系統概述

火災代理人模擬系統是一個基於 LLM（大語言模型）的多代理人火災逃生模擬系統。系統模擬建築物內發生火災時，多個具有不同人格特質的代理人如何根據其個性、記憶和當前情境做出逃生決策。

### 核心特性
- **動態火災傳播**：基於房間連接關係的動態煙霧和火勢蔓延
- **人格驅動決策**：每個代理人根據其人格特質、記憶和當前狀態做出決策
- **實時模擬**：使用 Server-Sent Events (SSE) 實現實時狀態更新
- **RAG 記憶系統**：代理人可以檢索相關記憶來輔助決策

### 主要類別

#### 1. Room（房間類）
```python
class Room:
    - name: str                    # 房間名稱
    - is_exit: bool               # 是否為出口
    - on_fire: bool               # 是否著火
    - smoke: bool                 # 是否有煙霧
    - blocked: bool               # 是否被封鎖
    - temperature: float           # 溫度（攝氏）
    - visibility: int              # 能見度（0-100%）
    - agents: List[str]           # 房間內的代理人ID列表
```

#### 2. Agent（代理人類）
```python
class Agent:
    - id: str                     # 代理人ID
    - name: str                   # 姓名
    - location: str               # 當前位置（房間名稱）
    - health: int                 # 健康值（0-100）
    - panic_level: int            # 恐慌程度（0-100）
    - known_fire: bool            # 是否知道火災
    - escaped: bool               # 是否已逃生
    - injured: bool               # 是否受傷
    - traits: List[str]           # 人格特質
    - social_abilities: Dict      # 社交能力
    - ability_attributes: Dict    # 能力屬性
```

#### 3. FireScenarioSimulator（模擬器主類）
```python
class FireScenarioSimulator:
    - rooms: Dict[str, Room]      # 房間字典
    - connections: Dict[str, List[str]]  # 房間連接圖
    - agents: List[Agent]         # 代理人列表
    - tick: int                   # 當前時間刻度
    - fire_start_room: str        # 起火房間
```

## 環境模型

### 房間布局

系統使用 2 行 4 列的網格布局：

```
上排：  [臥室A] [臥室B] [臥室C] [浴室]
        A1      A2      A3      A4

下排：  [走廊(跨2列)] [客廳] [廚房] [大門(出口)]
        B2            C1     C2     C3
```

### 房間連接圖

```python
connections = {
    '臥室A': ['走廊'],
    '臥室B': ['走廊'],
    '臥室C': ['走廊'],
    '浴室': ['走廊'],
    '走廊': ['臥室A', '臥室B', '臥室C', '浴室', '客廳', '廚房', '大門'],
    '客廳': ['走廊', '廚房'],
    '廚房': ['走廊', '客廳', '大門'],
    '大門': ['走廊', '廚房']
}
```

### 房間狀態更新

每個 tick，房間環境狀態會自動更新：

```python
def update_environment(self, tick):
    if self.on_fire:
        # 著火房間：溫度上升，能見度下降
        self.temperature += random.randint(10, 20)  # 每tick上升10-20°C
        self.visibility = max(0, self.visibility - random.randint(10, 30))  # 能見度下降10-30%
    
    if self.smoke:
        # 有煙霧房間：能見度下降
        self.visibility = max(0, self.visibility - random.randint(5, 15))  # 能見度下降5-15%
```

## 火災傳播機制

### 傳播流程圖

```
Tick 1: 初始起火
    ↓
Tick 2+: 動態傳播循環
    ├─→ 煙霧蔓延（優先）
    │   └─→ 從著火/有煙霧房間擴散到相鄰房間
    │
    └─→ 火勢蔓延（其次）
        └─→ 從著火房間蔓延到相鄰房間
```

### Tick 1: 初始起火

**觸發條件**：`self.tick == 1`

**執行邏輯**：
```python
fire_room = self.fire_start_room  # 使用配置的起火房間（預設：廚房）
self.rooms[fire_room].on_fire = True      # 設定為著火
self.rooms[fire_room].smoke = True        # 產生煙霧
self.rooms[fire_room].temperature = 200   # 溫度升高到200°C
```

**日誌輸出**：
```
[環境] {fire_room}起火！產生濃煙
```

**示例**：
- 如果 `fire_start_room = "廚房"`：
  ```
  [環境] 廚房起火！產生濃煙
  ```

---

### Tick 2+: 動態傳播機制

#### 2.1 煙霧蔓延機制

**觸發條件**：`self.tick >= 2`

**執行流程**：

```python
# Step 1: 找出所有煙霧源（著火房間 + 有煙霧的房間）
smoke_sources = [
    name for name, room in self.rooms.items() 
    if room.on_fire or room.smoke
]

# Step 2: 對每個煙霧源進行擴散檢查
for source_room in smoke_sources:
    connected_rooms = self.connections[source_room]  # 獲取相鄰房間
    
    for connected in connected_rooms:
        # Step 3: 檢查相鄰房間是否已有煙霧
        if not self.rooms[connected].smoke:
            # Step 4: 計算煙霧蔓延機率
            if self.rooms[source_room].on_fire:
                smoke_probability = 0.6  # 從著火房間：60%機率
            else:
                smoke_probability = 0.3  # 從僅有煙霧房間：30%機率
            
            # Step 5: 隨機決定是否蔓延
            if random.random() < smoke_probability:
                self.rooms[connected].smoke = True
                tick_log.append(f"[環境] 煙霧從{source_room}蔓延到{connected}")
```

**機率設計**：
- **從著火房間擴散**：60% 機率
- **從僅有煙霧房間擴散**：30% 機率

**示例場景**：

**Tick 2**：
- 廚房（著火）→ 檢查相鄰房間：客廳、走廊
  - 廚房 → 客廳：60% 機率，假設成功 → `客廳.smoke = True`
  - 廚房 → 走廊：60% 機率，假設失敗 → 無變化
- 日誌：`[環境] 煙霧從廚房蔓延到客廳`

**Tick 3**：
- 廚房（著火）→ 檢查相鄰房間：客廳（已有煙霧）、走廊
  - 廚房 → 客廳：跳過（已有煙霧）
  - 廚房 → 走廊：60% 機率，假設成功 → `走廊.smoke = True`
- 客廳（有煙霧）→ 檢查相鄰房間：走廊（已有煙霧）、廚房（著火）
  - 客廳 → 走廊：跳過（已有煙霧）
  - 客廳 → 廚房：跳過（著火房間）
- 日誌：`[環境] 煙霧從廚房蔓延到走廊`

---

#### 2.2 火勢蔓延機制

**觸發條件**：`self.tick >= 2`（在煙霧蔓延之後執行）

**執行流程**：

```python
# Step 1: 找出所有著火房間
fire_rooms = [name for name, room in self.rooms.items() if room.on_fire]

# Step 2: 對每個著火房間進行蔓延檢查
for fire_room in fire_rooms:
    connected_rooms = self.connections[fire_room]  # 獲取相鄰房間
    
    for connected in connected_rooms:
        # Step 3: 檢查相鄰房間是否已著火
        if not self.rooms[connected].on_fire:
            # Step 4: 計算火勢蔓延機率
            if self.rooms[connected].smoke:
                fire_probability = 0.4  # 相鄰房間有煙霧：40%機率
            else:
                fire_probability = 0.2  # 相鄰房間無煙霧：20%機率
            
            # Step 5: 隨機決定是否蔓延
            if random.random() < fire_probability:
                self.rooms[connected].on_fire = True
                self.rooms[connected].smoke = True      # 著火時同時產生煙霧
                self.rooms[connected].temperature = 200  # 溫度升高
                tick_log.append(f"[環境] 火勢從{fire_room}蔓延到{connected}！")
```

**機率設計**：
- **相鄰房間有煙霧**：40% 機率（煙霧預熱，更容易著火）
- **相鄰房間無煙霧**：20% 機率

**示例場景**：

**Tick 4**：
- 廚房（著火）→ 檢查相鄰房間：客廳（有煙霧）、走廊（有煙霧）、大門
  - 廚房 → 客廳：40% 機率（有煙霧），假設成功 → `客廳.on_fire = True`
  - 廚房 → 走廊：40% 機率（有煙霧），假設失敗 → 無變化
  - 廚房 → 大門：20% 機率（無煙霧），假設失敗 → 無變化
- 日誌：`[環境] 火勢從廚房蔓延到客廳！`

**Tick 5**：
- 廚房（著火）→ 檢查相鄰房間：客廳（已著火）、走廊（有煙霧）、大門
  - 廚房 → 客廳：跳過（已著火）
  - 廚房 → 走廊：40% 機率，假設成功 → `走廊.on_fire = True`
  - 廚房 → 大門：20% 機率，假設失敗 → 無變化
- 客廳（著火）→ 檢查相鄰房間：走廊（已著火）、廚房（已著火）
  - 全部跳過
- 日誌：`[環境] 火勢從廚房蔓延到走廊！`

### 完整 Tick 執行順序

每個 tick 的完整執行流程：

```
Tick N 開始
    ↓
1. 環境事件處理
    ├─ Tick 1: 初始起火
    └─ Tick 2+: 動態傳播
        ├─ 2.1 煙霧蔓延（優先）
        └─ 2.2 火勢蔓延（其次）
    ↓
2. 更新環境狀態
    └─ 所有房間執行 update_environment()
    ↓
3. 代理人感知與決策
    ├─ 感知火災（更新 known_fire）
    ├─ 更新狀態（健康、恐慌）
    ├─ 建立情境描述
    ├─ LLM 決策（如果 can_move）
    └─ 執行行動
    ↓
4. 記錄日誌
    └─ 返回 tick_log
    ↓
Tick N 結束
```

## 代理人決策系統

### 決策流程

```
每個 Tick，對每個代理人：
    ↓
1. 檢查狀態（escaped/injured）
    ↓
2. 感知環境（更新 known_fire）
    ↓
3. 更新狀態（健康、恐慌）
    ↓
4. 建立情境描述
    ↓
5. 構建 Prompt
    ├─ System Prompt（人格特質、記憶）
    └─ User Prompt（當前情境、狀態）
    ↓
6. LLM 生成決策（JSON格式）
    ↓
7. 解析並執行行動
```

### 狀態更新機制

#### 健康值（Health）更新

```python
def update_status(self, room):
    if room.on_fire:
        # 在著火房間：每tick減少5-15點健康
        self.health -= random.randint(5, 15)
    
    if room.smoke:
        # 在有煙霧房間：每tick減少1-5點健康
        self.health -= random.randint(1, 5)
    
    if self.health <= 0:
        self.injured = True
        self.can_move = False
```

**初始值**：100

**更新規則**：
- 著火房間：每 tick -5 到 -15（隨機）
- 有煙霧房間：每 tick -1 到 -5（隨機）
- 安全房間：無變化

#### 恐慌程度（Panic Level）更新

```python
def update_status(self, room):
    if room.on_fire:
        # 在著火房間：每tick增加10-20點恐慌
        self.panic_level = min(100, self.panic_level + random.randint(10, 20))
    
    if room.smoke:
        # 在有煙霧房間：每tick增加5-10點恐慌
        self.panic_level = min(100, self.panic_level + random.randint(5, 10))
```

**初始值**：0

**更新規則**：
- 著火房間：每 tick +10 到 +20（隨機，上限100）
- 有煙霧房間：每 tick +5 到 +10（隨機，上限100）
- 安全房間：無變化
- 選擇「panic」行動：額外 +20

### Prompt 結構

#### System Prompt

```python
system_template = """你是 {agent_name}，根據以下人格特質與記憶資料來做決策：
```

**參數說明**：

**情境描述生成邏輯**：

```python

if current_room.on_fire:
    situation += "房間著火了！"
elif current_room.smoke:
    situation += "房間有煙霧。"
else:
    situation += "房間目前安全。"

if agent.messages_received:

```

### 決策行動類型

#### 1. move（移動）
```python
if action == "move" and target in self.connections[agent.location]:
    old_location = agent.location
    self.rooms[old_location].agents.remove(agent.id)
    agent.location = target
    self.rooms[target].agents.append(agent.id)
    
    if target in ['大門']:
        agent.escaped = True
        agent.current_action = f"已逃生到{target}"
```

**限制**：
- 只能移動到相鄰房間（`target in self.connections[agent.location]`）
- 每回合只能移動1格

#### 2. stay（停留）
```python
# 不執行任何移動，保持當前位置
agent.current_action = "等待觀察"
```

#### 3. shout（呼救）
```python
elif action == "shout" and message:
    agent.current_action = f"呼救: {message}"
    # 通知同房間的其他人
    same_room_agents = [a for a in self.agents if a.location == agent.location and a.id != agent.id]
    for other_agent in same_room_agents:
        other_agent.messages_received.append({
            "from": agent.name,
            "message": message,
            "tick": self.tick
        })
        # 如果是火災警告，讓其他人知道火災
        if "火" in message or "危險" in message:
            other_agent.known_fire = True
```

#### 4. help_others（幫助他人）
```python
elif action == "help_others" and target:
    agent.current_action = f"幫助 {target}"
```

#### 5. search（搜尋）
```python
elif action == "search":
    agent.current_action = "搜尋出口"
```

#### 6. panic（恐慌）
```python
elif action == "panic":
    agent.current_action = "恐慌中"
    agent.panic_level = min(100, agent.panic_level + 20)  # 額外增加20點恐慌
```

## API 端點

### 1. 啟動模擬

**端點**：`POST /start-fire-simulation`

**請求體**：
```json
{
    "num_agents": 8,
    "max_rounds": 15,
    "simulation_speed": 1.0,
    "fire_start_room": "廚房"
}
```

**參數說明**：
- `num_agents`: 代理人數量（1-20）
- `max_rounds`: 最大回合數（tick數）
- `simulation_speed`: 模擬速度（秒，控制每個tick之間的延遲）
- `fire_start_room`: 起火房間名稱（可選，預設："廚房"）

**響應**：
```json
{
    "simulation_id": "fire_sim_b24e2d60",
    "status": "started",
    "message": "火災模擬已啟動，ID: fire_sim_b24e2d60"
}
```

### 2. SSE 串流

**端點**：`GET /simulation-stream/{simulation_id}`

**事件類型**：

1. **connected**：連接確認
```json
{
    "event": "connected",
    "data": {
        "message": "連接成功",
        "simulation_id": "fire_sim_b24e2d60",
        "connection_id": "f9be654d"
    }
}
```

2. **simulation_update**：模擬狀態更新
```json
{
    "event": "simulation_update",

                "health": 92,
                "panic_level": 17,

                "id": "A1",
                "display_name": "臥室A",
                "fire_level": 0,

            },
            "C2": {
                "id": "C2",
                "display_name": "廚房",
                "fire_level": 1,
                "smoke_level": 1
            }
        },
        "events": [
```

## 技術細節

### RAG 記憶檢索

系統使用 RAG（Retrieval-Augmented Generation）來檢索代理人的相關記憶：

```python
# 載入 RAG 資料庫
index, docs, _ = await self.chatbot.interviewer_obj.load_rag_database(agent.id)

# 檢索相似記憶
retrieved_docs, _ = await self.chatbot.interviewer_obj.retrieve_similar_docs(
    situation_context, index, docs, top_k=2
)
```

檢索到的記憶會包含在 System Prompt 中，幫助代理人做出更符合其背景的決策。

### 錯誤處理

1. **LLM 回應解析失敗**：
   - 返回預設行為：如果知道火災則移動，否則停留

2. **無效移動目標**：
   - 檢查 `target in self.connections[agent.location]`
   - 如果無效，行動被忽略

3. **SSE 連接中斷**：
   - 自動重試機制（最多5次）
   - 指數退避策略

火災代理人模擬系統通過動態的火災傳播機制和基於 LLM 的決策系統，實現了真實的火災逃生模擬。系統的核心優勢在於：
