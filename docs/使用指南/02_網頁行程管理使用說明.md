# 網頁行程管理系統使用說明

## 功能概述

網頁行程管理系統提供了一個直觀的網頁界面，讓你可以輕鬆管理每個角色的日常活動安排。通過這個系統，你可以：

- 一鍵為所有角色安排行程
- 個別管理每個角色的行程
- 即時查看角色狀態和當前任務
- 控制模擬系統的啟動和停止

## 訪問方式

1. 確保後端服務正在運行
2. 在瀏覽器中訪問：`http://localhost:20000/schedule-control`

## 界面說明

### 1. 狀態欄
- **模擬狀態**: 顯示生活模擬是否正在運行
- **總角色數**: 當前系統中的角色總數
- **有行程**: 已安排行程的角色數量
- **當前時間**: 系統當前時間

### 2. 一鍵安排行程
- **學生行程**: 適合學生角色，包含上學、放學、踢足球等活動
- **上班族行程**: 適合上班族角色，包含上班、下班、社交等活動
- **平衡行程**: 平衡型行程，包含學習、運動、社交等活動

### 3. 系統控制
- **啟動模擬**: 啟動生活模擬系統
- **停止模擬**: 停止生活模擬系統
- **清除所有行程**: 清除所有角色的行程安排
- **刷新資料**: 重新載入最新資料

### 4. 角色卡片
每個角色都會顯示一個卡片，包含：

#### 角色資訊
- **角色名稱**: 角色的姓名
- **行程狀態**: 顯示是否有啟用的行程
- **當前位置**: 角色目前所在的位置
- **健康狀態**: 角色的健康值百分比
- **能量狀態**: 角色的能量值百分比
- **快樂狀態**: 角色的快樂值百分比

#### 當前任務
- 顯示角色當前正在執行的任務
- 包含任務名稱和開始時間

#### 操作按鈕
- **啟用/停用**: 切換角色行程的啟用狀態
- **清除行程**: 清除該角色的行程安排
- **安排行程**: 為沒有行程的角色安排新行程

## 使用步驟

### 1. 啟動系統
1. 訪問網頁界面
2. 點擊「啟動模擬」按鈕
3. 等待系統載入角色資料

### 2. 安排行程
1. 選擇想要的行程類型（學生、上班族、平衡）
2. 點擊「套用到所有角色」按鈕
3. 系統會自動為所有角色安排對應的行程

### 3. 個別管理
1. 在角色卡片中找到要管理的角色
2. 使用對應的按鈕進行操作：
   - 點擊「啟用/停用」切換行程狀態
   - 點擊「清除行程」移除行程安排
   - 點擊「安排行程」為角色添加新行程

### 4. 監控狀態
- 定期點擊「刷新資料」查看最新狀態
- 觀察角色卡片中的狀態變化
- 查看當前任務的執行情況

## 常見問題

### Q: 網頁無法載入
A: 檢查後端服務是否正在運行，確認端口20000是否可用

### Q: 角色狀態不更新
A: 點擊「刷新資料」按鈕，或檢查模擬系統是否正在運行

### Q: 行程安排失敗
A: 確保模擬系統已啟動，檢查後端日誌是否有錯誤訊息

### Q: 角色不執行任務
A: 確認角色的行程已啟用，檢查模擬時間是否正確

## 技術特性

- **響應式設計**: 支援桌面和移動設備
- **即時更新**: 自動刷新角色狀態
- **直觀界面**: 清晰的視覺設計和操作流程
- **錯誤處理**: 完善的錯誤提示和處理機制
- **批量操作**: 支援一鍵操作多個角色

## 注意事項

1. **模擬時間**: 系統使用模擬時間，每分鐘代表1小時
2. **行程優先**: 有行程的角色會優先執行排程任務
3. **狀態同步**: 定期刷新以獲取最新狀態
4. **操作確認**: 重要操作會有確認提示
5. **錯誤處理**: 操作失敗時會顯示詳細錯誤訊息

## 進階功能

### 自定義行程
可以通過修改後端代碼來添加自定義行程模板。

### 條件執行
行程任務支援條件執行，可以根據角色狀態決定是否執行。

### 動態調整
可以通過網頁界面動態調整行程狀態，無需重啟系統。

## 故障排除

### 檢查清單
1. 後端服務是否運行
2. 端口20000是否可用
3. 瀏覽器是否支援JavaScript
4. 網路連接是否正常

### 日誌查看
```bash
# 查看後端日誌
tail -f logs/backend.log

# 檢查API響應
curl http://localhost:20000/api/life-simulation/all-agents-status
```

### 重置系統
如果遇到問題，可以：
1. 停止模擬系統
2. 清除所有行程
3. 重新啟動模擬
4. 重新安排行程
