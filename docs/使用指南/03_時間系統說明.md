# 時間系統說明

## 概述

系統使用**模擬時間**來管理角色的日常活動，而不是真實時間。這讓角色可以在短時間內完成一整天的活動。

## 時間系統架構

### 1. 模擬時間變數
```python
# 在 LifeSimulationManager 中
self.current_time = datetime.now().replace(hour=8, minute=0, second=0, microsecond=0)
# 模擬時間從早上8點開始
```

### 2. 時間加速機制
```python
self.time_speed = 60.0  # 時間加速倍率
# 每1秒真實時間 = 1分鐘模擬時間
# 每1分鐘真實時間 = 1小時模擬時間
```

### 3. 時間更新循環
```python
async def update_agents(self):
    # 更新模擬時間（每分鐘前進1小時）
    self.current_time += timedelta(minutes=1)
    
    # 更新排程代理人
    await self.update_scheduled_agents()
```

## 時間判斷邏輯

### 1. 任務時間範圍計算
```python
def get_current_scheduled_task(self, agent_id: str):
    for task in schedule.tasks:
        task_start = task["start_time"]  # 例如: "08:00"
        task_duration = task["duration"]  # 例如: 240 (分鐘)
        
        # 計算任務開始和結束時間
        start_hour, start_min = map(int, task_start.split(":"))
        start_time = self.current_time.replace(hour=start_hour, minute=start_min, second=0, microsecond=0)
        end_time = start_time + timedelta(minutes=task_duration)
        
        # 檢查當前時間是否在任務時間範圍內
        if start_time <= self.current_time <= end_time:
            return task
```

### 2. 任務切換機制
```python
async def update_scheduled_agents(self):
    for agent_id, agent in self.agents.items():
        schedule = self.schedules.get(agent_id)
        if not schedule or not schedule.is_active:
            continue
        
        # 檢查是否有新的任務需要開始
        current_task = self.get_current_scheduled_task(agent_id)
        if current_task:
            # 檢查代理人是否在執行正確的任務
            current_activity = agent.current_activity.get("name", "")
            expected_activity = current_task["name"]
            
            if current_activity != expected_activity:
                # 開始新任務
                await self.start_scheduled_task(agent, current_task)
```


### 時間判斷過程
1. **08:00** - 系統檢查到當前時間是08:00，開始"上學"任務
2. **08:01-11:59** - 持續執行"上學"任務
3. **12:00** - 系統檢查到當前時間是12:00，切換到"午餐"任務
4. **12:01-12:59** - 持續執行"午餐"任務
5. **13:00** - 系統檢查到當前時間是13:00，切換到"放學回家"任務

## 時間系統特點

### 1. 模擬時間 vs 真實時間
- **模擬時間**: 系統內部使用的時間，從08:00開始
- **真實時間**: 系統運行的實際時間
- **時間比例**: 1分鐘真實時間 = 1小時模擬時間

### 2. 時間精度
- 最小時間單位: 1分鐘
- 任務持續時間: 以分鐘為單位
- 時間檢查頻率: 每1秒檢查一次

### 3. 時間同步
- 所有角色使用相同的模擬時間
- 時間更新是同步的
- 任務切換是即時的

## 時間控制參數

### 1. 時間速度
```python
self.time_speed = 60.0  # 可調整的參數
# 60.0 = 1分鐘真實時間 = 1小時模擬時間
# 30.0 = 1分鐘真實時間 = 30分鐘模擬時間
# 120.0 = 1分鐘真實時間 = 2小時模擬時間
```

### 2. 模擬循環頻率
```python
await asyncio.sleep(1.0 / self.time_speed)
# 控制模擬更新的頻率
```

## 時間系統優勢

### 1. 快速模擬
- 可以在短時間內觀察一整天的活動
- 適合測試和演示

### 2. 精確控制
- 每個任務都有明確的開始和結束時間
- 時間判斷邏輯清晰

### 3. 可調節性
- 可以調整時間速度
- 可以修改任務時間表

## 時間系統限制

### 1. 時間精度
- 最小時間單位是1分鐘
- 無法處理秒級精度的任務

### 2. 時間同步
- 所有角色必須使用相同的時間
- 無法為不同角色設定不同的時間速度

### 3. 時間重置
- 模擬時間不會自動重置
- 需要手動重置或重新啟動

## 實際運作流程

1. **系統啟動**: 模擬時間設為08:00
2. **時間循環**: 每1秒真實時間，模擬時間前進1分鐘
3. **任務檢查**: 每1秒檢查所有角色的當前任務
4. **任務切換**: 當時間到達任務開始時間時，自動切換任務
5. **狀態更新**: 更新角色的位置、活動和狀態

## 總結

系統使用**模擬時間**來管理角色的日常活動，通過時間範圍判斷來決定何時執行什麼任務。這種設計讓系統可以在短時間內模擬一整天的活動，同時保持時間邏輯的清晰和可控。
