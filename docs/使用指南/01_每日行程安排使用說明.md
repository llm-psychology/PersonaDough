# 每日行程安排系統使用說明

## 功能概述

每日行程安排系統讓你可以一鍵為所有角色安排固定的日常活動，讓他們自動按照時間表執行任務，如：
- 自動上學/上班
- 自動回家睡覺
- 自動用餐
- 自動運動和社交

## 可用的行程類型

### 1. 學生行程 (student)
- **07:00** 起床
- **07:30** 吃早餐
- **08:00** 上學 (4小時)
- **12:00** 午餐
- **16:00** 放學回家
- **17:00** 踢足球 (2小時)
- **19:00** 晚餐
- **20:00** 休息
- **22:00** 睡覺

### 2. 上班族行程 (worker)
- **06:30** 起床
- **07:00** 吃早餐
- **08:00** 上班 (8小時)
- **12:00** 午餐
- **17:00** 下班回家
- **18:00** 晚餐
- **19:00** 社交活動
- **21:00** 休息
- **22:00** 睡覺

### 3. 平衡行程 (balanced)
- **07:30** 起床
- **08:00** 吃早餐
- **09:00** 學習/工作 (3小時)
- **12:00** 午餐
- **14:00** 運動
- **16:00** 休息
- **18:00** 社交
- **19:30** 晚餐
- **20:30** 自由時間
- **22:00** 睡覺

## API 使用方法

### 1. 一鍵安排所有角色
```bash
POST /api/schedule/apply-to-all?schedule_type=student
```

### 2. 為特定角色安排行程
```bash
POST /api/schedule/apply-to-agent/{agent_id}?schedule_type=worker
```

### 3. 查看所有行程安排
```bash
GET /api/schedule/all
```

### 4. 查看特定角色行程
```bash
GET /api/schedule/agent/{agent_id}
```

### 5. 切換行程狀態
```bash
POST /api/schedule/toggle/{agent_id}
```

### 6. 清除特定角色行程
```bash
DELETE /api/schedule/agent/{agent_id}
```

### 7. 清除所有行程
```bash
DELETE /api/schedule/clear-all
```

### 8. 獲取行程模板
```bash
GET /api/schedule/templates
```

## Unity 使用方式

### 1. 添加 ScheduleManager 腳本
將 `ScheduleManager.cs` 添加到 Unity 場景中的 GameObject 上。

### 2. 設定 UI 元件
- 連接按鈕到對應的方法：
  - `ApplyStudentSchedule()` - 安排學生行程
  - `ApplyWorkerSchedule()` - 安排上班族行程
  - `ApplyBalancedSchedule()` - 安排平衡行程
  - `ClearAllSchedules()` - 清除所有行程

### 3. 設定 API 地址
在 ScheduleManager 中設定 `apiBaseUrl` 為你的後端地址。

## 使用範例

### Python 範例
```python
import aiohttp
import asyncio

async def arrange_schedules():
    async with aiohttp.ClientSession() as session:
        # 為所有角色安排學生行程
        async with session.post("http://localhost:20000/api/schedule/apply-to-all?schedule_type=student") as response:
            result = await response.json()
            print(f"安排結果: {result['message']}")

asyncio.run(arrange_schedules())
```

### Unity C# 範例
```csharp
public class GameManager : MonoBehaviour
{
    public ScheduleManager scheduleManager;
    
    void Start()
    {
        // 遊戲開始時自動安排學生行程
        scheduleManager.ApplyStudentSchedule();
    }
    
    public void OnStudentButtonClick()
    {
        scheduleManager.ApplyStudentSchedule();
    }
    
    public void OnWorkerButtonClick()
    {
        scheduleManager.ApplyWorkerSchedule();
    }
}
```

## 注意事項

1. **模擬時間**: 系統使用模擬時間，每分鐘代表1小時
2. **角色需求**: 有行程的角色會優先執行排程任務，忽略自主決策
3. **位置移動**: 角色會自動移動到任務指定的位置
4. **狀態更新**: 角色的健康、能量、快樂等狀態會根據活動自動調整
5. **行程切換**: 可以隨時啟用/停用或清除行程安排

## 故障排除

### 常見問題

1. **角色不執行任務**
   - 檢查行程是否已啟用
   - 確認模擬是否正在運行
   - 查看後端日誌是否有錯誤

2. **API 連接失敗**
   - 確認後端服務是否啟動
   - 檢查 API 地址是否正確
   - 確認防火牆設定

3. **行程不生效**
   - 重新啟動生活模擬
   - 清除現有行程後重新安排
   - 檢查角色是否存在

### 日誌查看

```bash
# 查看後端日誌
tail -f logs/backend.log

# 查看 Unity 控制台
# 在 Unity Editor 中查看 Console 窗口
```

## 進階功能

### 自定義行程
可以修改 `life_simulation_backend.py` 中的 `default_schedules` 來添加自定義行程模板。

### 條件執行
行程任務支援條件執行，可以根據角色的狀態決定是否執行特定任務。

### 動態調整
可以通過 API 動態調整行程時間和活動類型，無需重啟系統。

## 技術細節

- **後端**: FastAPI + Python
- **前端**: Unity C#
- **數據存儲**: 記憶體 + JSON 文件
- **通訊協議**: HTTP REST API
- **時間系統**: 模擬時間 (1分鐘 = 1小時)
